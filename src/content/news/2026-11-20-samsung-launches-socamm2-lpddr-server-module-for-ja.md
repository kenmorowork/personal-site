Samsung introduced an LPDDR-based SOCAMM2 memory module for agentic AI servers, pitched on performance, upgrade flexibility and power/space efficiency; no figures were disclosed in the accessible report.

**Why it matters:** SOCAMM2 extends the low-power memory push into AI servers; with no figures disclosed, the checkpoint is adoption by server makers rather than the launch itself.

**三星推出面向智能体AI服务器的SOCAMM2内存模组**



三星发布基于LPDDR的SOCAMM2服务器内存模组，主打性能、升级灵活性与能效/空间效率；可查阅的报道未披露具体数字。



SOCAMM2将低功耗存储的推进延伸至AI服务器；由于未披露具体数字，检验点在于服务器厂商的采用而非发布本身。
