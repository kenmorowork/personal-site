# AI向け指示書：kenmorozumi.com の更新と投稿

この文書は、Claude、ChatGPT、Gemini など、どのAIでも同じ手順で Ken のサイトを更新できるようにするための指示書です。サイト本体のリポジトリにも同じ内容が入っています。作業を始める前に、リポジトリ内の `AGENTS.md` を必ず読んでください。ルールは `AGENTS.md` が基準です。

## 1. 現在の状況

- サイトは **kenmorozumi.com** です。日本語版が `/ja/`、英語版が `/en/` にあります。
- サイトの持ち主は Ken（諸角憲史）です。運営名義は **J-Core Fundamental Research** です。
- 原稿とコードは GitHub のリポジトリ **kenmorowork/personal-site** に置いてあります。
- 公開の仕組みは単純です。リポジトリの `main` ブランチが更新されると、Cloudflare が自動でサイトを組み立てて公開します。公開まではおよそ1分です。
- ドメインは Cloudflare で管理しています。有効期限は 2027-11-23 です。ドメインと DNS の設定は、この指示書の対象ではありません。触らないでください。

## 2. アクセスの取り方

サイトを更新するには、GitHub への書き込み権限が必要です。AIごとに専用のトークン（鍵）を1つずつ使います。他のAIのトークンを使い回さないでください。

トークンを持っていない場合は、Ken に発行を依頼してください。発行の設定は次のとおりです。

- 種類は Fine-grained personal access token です。
- Resource owner は **kenmorowork** です。
- Repository access は **Only select repositories** を選び、**personal-site** だけを指定します。
- Permissions は **Contents: Read and write** のみです。Metadata は自動で付きます。
- 有効期限は90日を目安にします。

トークンの値は秘密情報です。リポジトリに保存しないでください。ファイルに書き写さないでください。チャットに貼るよう求めないでください。作業環境の認証情報としてだけ使います。

なお、Muse（ホッサン）はトークンを使いません。GitHub コネクタ経由で接続済みです。この節は、トークン方式で接続する他のAIのためのものです。

## 3. リポジトリの歩き方

- サイトは Astro で作られています。ビルドは `npm run build`、公開は Cloudflare が自動で行います。
- 記事やレポートの中身は `src/content/` の下に Markdown ファイルとして置いてあります。コレクションは `news`、`reports`、`portfolio` の3つです。
- 1つのコンテンツには日本語版と英語版の両方があります。片方だけを追加しないでください。
- 各ファイルの先頭にはフロントマター（タイトル、日付、タグなどの情報）を書きます。書式は `src/content.config.ts` と既存ファイルが基準です。新しい書式を発明しないでください。
- レイアウトやデザインのコード（`src/components/`、`src/layouts/`）は、コンテンツ追加の作業では触りません。

## 4. 更新の手順

1. `main` から作業用ブランチを切ります。名前は作業内容が分かるものにします。
2. `src/content/` に Markdown ファイルを追加、または既存ファイルを編集します。日本語版と英語版の両方をそろえます。
3. ローカルで `npm run build` を実行し、エラーが出ないことを確認します。
4. ブランチを push し、`main` 向けのプルリクエストを作ります。
5. 内容を確認してからマージします。マージすると Cloudflare が自動で公開します。
6. 公開後に `https://kenmorozumi.com/ja/` と関係するページを開き、表示を確認します。確認できたら Ken に報告します。

小さな誤字修正のような変更でも、手順は同じです。`main` へ直接 push しないでください。

## 5. コンテンツのルール

- 数字には必ず単位と、比較の基準（前年比など）を付けます。出典がある場合は出典と日付を書きます。
- 取れなかったデータは推測で埋めません。「未取得」と明記します。
- 日本語の文は体言止めにしません。文は最後まで言い切ります。
- 個別銘柄の買いや売りの推奨は書けません。投資助言に当たる表現は避けてください。
- 運営名義は **J-Core Fundamental Research** です。旧名義は使わないでください。
- Ken の顔写真は使いません。プロフィール画像にはラグドールの猫の写真を使います。
- 既存の記事の事実関係を、根拠なく書き換えないでください。

## 6. してはいけないこと

- ドメイン、DNS、Cloudflare の設定を変更すること。
- `wrangler.jsonc` を変更すること。
- トークンやパスワードなどの秘密情報をリポジトリに入れること。
- お金がかかる操作をすること。費用が発生する作業は、事前に Ken の承認が必要です。
- サイトの公開範囲を変えること（非公開化、別ドメインへの移転など）。

## 7. Ken への確認が必要なこと

次の場合は、作業を止めて Ken に確認してください。

- 費用が発生する作業です。
- デザインやサイト構成を変える作業です。
- 記事の公開範囲や、過去の記事の削除に関わる作業です。
- ビルドが失敗して、原因が分からない場合です。

それ以外の通常のコンテンツ追加と更新は、この指示書と `AGENTS.md` の範囲で進めて構いません。完了したら、何を追加したか、公開URLはどこか、表示確認をしたかを Ken に報告してください。
