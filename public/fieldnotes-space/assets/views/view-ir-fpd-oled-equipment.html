0. エグゼクティブサマリー

Desk view： FPD装置は「LCDの時代の汎用設備市場」から「OLEDの世代交代にだけ発生する、案件単位の特注設備市場」へ変質した。需要は平準化せず、①蒸着（evaporation）という単一工程の供給者交代、②FMM（ファインメタルマスク）を使わない次世代パターニング（ViP／FLiPP／IJP）の成否、③中国地方政府の共同出資モデルが生む「需要の前倒しと過剰能力」の3点で決まる。2026年は G8.6 IT OLED 3案件（BOE B16、Visionox V5、CSOT t8）と Samsung Display A6 の搬入が重なる異例のピーク年であり、最新の Counterpoint 推計では世界のディスプレイ装置支出は 2026年に 108億ドル（前年比+61%） へ跳ねた後、2027年には 55億ドル（同−49%） へ半減する[2]。装置メーカーの収益は「市場成長」ではなく「どのファブの、どの工程の枠を取ったか」で決まる — これが本セクターの本質である。

2026年11月までの事実はこの見方を補強した：

  • 蒸着の独占が G8.6 で初めて崩れた。 G6以下の量産蒸着は Canon Tokki（キヤノン完全子会社）が事実上独占してきたが[25]、BOE B16（成都、投資額630億元、月産32,000枚）では Phase 1・Phase 2 とも蒸着本体を韓国の Sunic System が受注した[11]。価格は Tokki 製の約半分と報じられている（Samsung Display 向け Tokki 2台で8,000〜9,000億ウォンに対し、BOE 向け Sunic 2台は4,000億ウォン台半ば）[11]（報道経由）。Sunic の売上は2023年624億ウォン → 2025年 5,158億ウォン（営業利益1,115億ウォン、率約22%）へ8倍超に膨らんだ[12]。
  • 量産開始の順序も逆転した。 BOE B16 は2026年6月17日に量産・顧客納入を開始し[10]、Samsung Display A6（投資4.1兆ウォン[9]）より約3週間先行したと報じられた[36]。一方で B16 ではガラス割れの問題が半年解消していないとの報道もある（原因は未特定とされる）[19]付随資料 — 新規格ラインの歩留まりリスクは装置側の評価に直結する。
  • LG Display は G8.6 新ラインを持たない唯一の大手になった。 同社は2026年1月の決算で G8.6 IT OLED 投資に慎重姿勢を示し[20]、代わりに既存 G8.5 坡州ラインの転用を前提とするマスクレス技術 FLiPP を掲げ、蒸着装置の初号機を韓国の YAS から約2,000億ウォンで試作調達する方向と報じられた（量産時期は未定）[19]。新規ライン投資ではなく「工程置換」で対抗する賭けである。
  • LCD大型装置の需要は構造的に消えた。 LG Display は広州 G8.5 LCD 工場を TCL CSOT へ15.4億ドルで売却し（2025年3月完了）[13]、Samsung Display は2022年に LCD から撤退済み。日本の SDP（堺）は2024年9月に生産を終え、跡地は SoftBank／KDDI の AI データセンターになった[14]。残る LCD 装置需要は中国内の更新・移設と、Tianma TM19 等の限られた新設のみである[1]。
  • JOLED の教訓は「工程の正しさ ≠ 事業の成立」である。 印刷方式 OLED の先駆者 JOLED は2023年3月27日に負債337億円で破綻した[15]。技術・知的財産は Japan Display へ、印刷装置は CSOT へ移り、その系譜が CSOT の G8.6 印刷ライン t8（295億元、2026年10月31日に装置搬入開始、量産は2027年Q4計画）[16] に繋がっている。装置需要の持続性は、パネルメーカーの財務耐久力と一体で見なければならない。

1. 業界定義・範囲

本レポートの対象は FPD（フラットパネルディスプレイ）製造装置、すなわちガラス基板（およびシリコンウェーハ上の OLEDoS）から LCD／OLED パネルを作るための生産設備である。工程は大きく3層に分かれる：

  1. バックプレーン工程 — TFT（薄膜トランジスタ）形成。露光（FPD リソグラフィ）、成膜（CVD／スパッタ）、エッチング、レーザーアニール（ELA：エキシマレーザーによる多結晶化）、イオン注入、コータ／デベロッパ。半導体前工程と技術的には近いが、基板サイズ（最大 G10.5＝2,940mm×3,370mm 級）が2桁大きく、装置の設計思想・供給者が別である。本稿は半導体前工程装置（レポート No. 14）と重複させない： Nikon／Canon の半導体露光、東京エレクトロンの半導体コータ／デベロッパ等は No. 14 の範囲であり、ここでは FPD 専用機のみを扱う。
  2. フロントプレーン工程 — 発光層の形成。OLED では真空蒸着（FMM 方式の RGB 並置、白色 OLED＋カラーフィルタ、青色 OLED＋QD 変換）、インクジェット印刷（IJP）、封止（TFE：薄膜封止、ガラス封止）、レーザーリフトオフ（LLO）。LCD では配向・液晶注入・カラーフィルタ工程が対応する。
  3. 検査・リペア・搬送 — AOI（自動光学検査）、アレイ検査、リペア、基板搬送・ストッカ、クリーンルーム付帯設備。

含むもの： 上記の専用装置、および OLEDoS（シリコン上 OLED、マイクロ OLED）用蒸着装置。含まないもの： パネル材料そのもの（発光材料・FMM・封止材は §4 の上流として扱い、市場規模の深掘りはしない）、モジュール組立・セット事業、半導体装置（No. 14）、電子部品（No. 15）。

世代（Generation）の定義： マザーガラスの寸法で呼ぶ。G6＝1,500mm×1,850mm 級（スマートフォン OLED の主戦場）、G8.5＝2,200mm×2,500mm 級（TV 用 WOLED／QD-OLED、IT の従来ライン）、G8.6＝2,290mm×2,620mm[10][16]（IT OLED 新ラインの標準）、G10.5＝2,940mm×3,370mm 級（大型 LCD）。世代が上がるほど1枚から取れる IT／TV パネル数が増え、装置は大型化・高額化する。

隣接セクターとの境界： Applied Materials の MAX OLED（フォトリソグラフィ方式のパターニング基盤）のように、半導体装置メーカーがディスプレイ工程へ横展開する動きは本稿の対象に含める（装置の売り先がパネルメーカーであるため）。逆に、パネルメーカー自身の設備投資額は「装置市場の需要側」として §2・§5 で扱い、パネル事業の損益分析は最小限に留める。

3. 需要ドライバーと定量的見通し

3.1 IT OLED（タブレット・ノートPC・モニタ）— 現在の装置需要のほぼ全て

装置需要の起点は Apple の IT 製品 OLED 化である。iPad Pro の OLED 化（2024年、タンデム構造）でタブレット用 OLED 出荷は2024年に前年比+202%と跳ね[8]、続く MacBook Pro の OLED 化が G8.6 ライン投資の引き金になった。Samsung Display A6 は「年1,000万枚のノートPCパネル」供給能力を目標に4.1兆ウォンを投じる計画として発表された[9]（会社計画）。TrendForce は OLED MacBook Pro の出荷を2027年に最大150万台と予測し、Samsung Display が現時点で Apple 向け OLED MacBook Pro の単独供給者と報じられている[36]（報道経由）。

定量面の裏付け： - 大型 OLED 出荷は2026年に+18.8%（3,880万枚）、ノートPC向けは+66%（Omdia）[32]。 - ノートPC用 OLED パネル出荷は2026年 +50%、2027年 +24%（Counterpoint）[2]付随資料（機関予測）。 - IT OLED パネル売上は2024年25億ドル → 2029年89億ドル（CAGR 28.6%、Omdia、Samsung Display の投資発表時に引用された数値）[9]付随資料（機関予測）。 - タンデム構造の採用は装置需要を直接押し上げる： 発光層を2層積むため蒸着工程の処理量が増え、タンデム比率はタブレット＋ノートPCで2026年に36%へ上昇する[34]。UBI Research は、Visionox V5 の Phase 1 ではタンデム前提のため蒸着装置1台当たりの実効能力が単層比で約半分になると指摘する[18] — 同じ基板能力でも必要な蒸着台数が増える構造である。

3.2 スマートフォン OLED — 成熟し、装置需要は「置換・転換」が中心

スマートフォン AMOLED 出荷は2025年8.36億枚がピーク圏で、2026年は7.78億枚（−7%）の見通し[42]（機関予測）。新規 G6 ラインの大型投資は一巡し、装置需要は LTPO 化・フレキシブル転換・既存ラインの能力増強（例： G6 モバイルライン2件のフレキシブル転換が2025年4月の上方修正要因[6]）へ移っている。Ulvac が「タブレット向け OLED の追加・改造案件が継続」と述べる[28]のもこの層の需要である。中国勢の G6 稼働率上昇が追加投資を支える構図だが、DSCC は AMOLED 業界の供給過剰が2028年まで続くとみている[8]付随資料 — スマートフォン向けの新規大型投資が再加速する根拠は現時点では弱い。

3.3 TV（大型 OLED）— 稼働率ビジネスであり、新規装置需要は限定的

大型 OLED は LG Display の WOLED（白色 OLED＋カラーフィルタ、G8.5）と Samsung Display の QD-OLED（青色 OLED＋QD 変換層の印刷、G8.5）の2方式が併存する。いずれも既存ラインの稼働率と製品ミックス（モニタへの振替）で収益を作る段階にあり、Omdia は韓国メーカーが G8.5 ラインの能力を TV からモニタへ振り向ける動きを指摘する[32]。LG Display の大型 OLED 出荷見通しは2026年に700万枚台後半（前年比 約+20%）、うちモニタが約20%[20]付随資料（会社見通し）。TV 向けの新規ライン投資は本稿の確認範囲では表明されておらず、装置需要としては「既存ラインの維持・転用」が中心である。

3.4 OLEDoS／マイクロ OLED（XR）— 小さいが装置単価が高い新市場

近接表示（AR/VR）向け OLEDoS は、蒸着装置の新しい需要先である。Omdia は近接表示売上を2026年に12億ドル（前年比+200%超）と予測する[37]（機関予測）。供給側では Sony が OLEDoS 供給の約70%を占めるとされ[38]、Samsung Display は米 eMagin を2.18億ドルで買収し（2023年10月完了）、直接パターニング（dPd）技術を手に入れた[31]。装置側の主役は Sunic System で、12インチウェーハ用 OLEDoS 蒸着装置を累計10台超・5社超へ納入したとされ[38]、OLEDoS 蒸着装置のシェアは同社推定で90%超[12]、第三者推定では80%超[12]付随資料、Micro OLED 蒸着全体では50%超[37]と、推計の幅が大きい（§6 で併記）。Canon Tokki は2026年6月の SID で12インチ RGB OLEDoS 用蒸着システムのデモ機を発表したが、量産対応の RGB OLEDoS 蒸着システムは現時点で世界に存在しないとされる[37] — この工程は「実証 → 量産装置」の転換点にあり、Samsung Display が1台 約1,500億ウォン規模の RGB OLEDoS 蒸着装置を計画しているとの報道もある[38]（業界推計、報道経由）。

3.5 LCD — 退出と集約。装置需要は中国の内側だけ

  • Sharp／SDP： 堺の G10 ラインは2024年9月末に生産終了[14]。跡地は SoftBank（約1,000億円、AI データセンター、150MW 級）と KDDI（約100億円、大阪堺データセンターは2026年1月稼働）が取得した[14]。さらに亀山第2工場は2026年10月末に生産を停止し、飛騨（Hisai）工場は日東電工へ222億円で売却される（2026年12月譲渡予定）[41] — 日本の大型 LCD 生産は事実上終わった。

5.3 供給側の構造変化

2026年の装置支出108億ドル[2]の裏側では、供給者の国籍構成が変わった。支出の83–85%が発生する中国[4][6]では、地場・韓国系サプライヤーの採用が進み（B16 の蒸着＝Sunic、蒸着源＝韓国 FINEST＋中国 SSOT[11]）、日系が残るのは FPD 露光（Nikon／Canon）とスパッタ（Ulvac）等の限定工程になった。2027年の供給者シェア予測で Sunic が16%で首位に立つ[2]のは、この構造変化の集計結果である。

6. 競争環境とシェア

  • 構造： 工程ごとに別の寡占がある「工程別寡占の集合」。 露光は Nikon／Canon の2社、量産蒸着（G6以下）は Canon Tokki の事実上の単独供給が長く続き[25]、G8.6 蒸着で Sunic が第2の供給者として認定された。封止 IJP は Kateeva、QD 印刷は SEMES、スパッタは Ulvac と Applied Materials（AKT）、ELA は AP Systems が強い。市場全体の供給者シェアは案件配分で年単位に入れ替わる（2024年： Canon 13%が首位[3] → 2027年予測： Sunic 16%が首位[2]）。
  • 蒸着の価格破壊が起きた。 BOE が Sunic 2台に支払う額は4,000億ウォン台半ばとされ、Samsung Display が Tokki 2台に支払う8,000〜9,000億ウォンの約半分である[11]（いずれも報道推計）。性能・歩留まりの実績差がこの価格差に見合うかは、B16 の量産立上げ（ガラス割れ問題の報道[19]付随資料を含む）が最初の検証になる。逆に言えば、Tokki の価格が「独占価格」だったのか「歩留まりの対価」だったのかが、2027年の B16 Phase 2 と Samsung Display の次期発注で判定される。
  • 設置ベース vs フロー： 蒸着・露光とも、一度プロセスに組み込まれると装置の切替はライン全体の再認定を意味し、フローシェアの変動は設置ベースの変動より速い。Sunic のフローでの躍進（2025年売上5,158億ウォン[12]）に対し、G6 以下の設置ベースは依然 Tokki が支配的であり、保守・改造需要は Tokki 側に残る。
  • 地域 champions と排除の力学： 中国は支出の83–85%[4][6]を占める最大市場だが、調達は「中国で認定された供給者」に寄る。韓国は Samsung Display／LG Display の地元調達（Sunic、YAS、AP Systems、SEMES）で自国装置産業を維持し、日本は露光・スパッタ・検査等の「代替の効かない工程」に退いて高収益を守る — という三国分業が2026年の姿である。米 Applied Materials は AKT（成膜・封止）と MAX OLED（マスクレス基盤）の2正面で全地域に売る唯一の西側プレイヤーである。
  • パネル側のシェア（装置需要の配分）： 能力ベースでは中国が全ディスプレイの74%（2028年）へ[35]、OLED 能力では中国が2028年に韓国を追い越し、フレキシブル OLED 能力では BOE（26%）が Samsung Display（24%）を上回る見通しである[35]（機関予測）。装置メーカーの顧客構成はこの能力地図に収束していく。

未取得： 工程別の公式シェア統計（蒸着の Tokki vs Sunic の金額シェア、FPD 露光の金額シェア）。台数ベースは Nikon の開示[26]のみ取得できた。

8. 技術ロードマップ

段階を分けて記す（研究／試作／認定／量産）。

  • タンデム（2層発光）— 段階： 量産（拡大中）。 iPad Pro で実用化され、タブレット＋ノートPC のタンデム比率は2026年に36%へ[34]。蒸着の処理量を増やすため装置需要にはプラスだが、製造コストは単層比+50〜75%[34]で、最終製品の価格転嫁が前提になる。
  • FMM の限界と大型化 — 段階： 物理的制約が顕在化。 G8.6 のマザーガラスで FMM の自重たわみ・熱膨張を抑えることが難しくなり、B16 では地場 FMM の新規開発案件が並走した[10]付随資料。マスクレス化の技術的動機である。
  • Visionox ViP（フォトリソグラフィ方式）— 段階： 小型で量産、G8.6 は立上げ中。 FMM を使わずリソグラフィで画素を区切る方式で、開口率は従来 FMM の29% → 69%へ改善するとされる[18]。Honor のスマートウォッチ向けにタンデム＋ViP パネルが量産出荷され、G6 ラインのウェアラブル向け歩留まりは約85%と公表された一方、スマートフォン超のサイズでは FMM 方式より歩留まりが相当低いと報じられる[18]。V5 Phase 1（月産8,000枚）の2027年量産が最初の本格検証である。
  • LG Display FLiPP — 段階： 試作機調達。 基板全面に発光材料を成膜し、保護層の上からリソグラフィ＋エッチングで不要部を除く FMM レス方式。開口率は約55%改善し、輝度1.6倍／寿命2.4倍／消費電力13%減のいずれかが得られると LG Display は説明する[19]付随資料。既存 G8.5 WOLED ライン（坡州 P8）の転用が検討され、蒸着初号機は YAS 製・約2,000億ウォン、量産には RGB 3台が必要とされる[19]。会社自身は「投資規模・量産時期は未確定」と繰り返しており[20]、2027年上期の投資判断の有無が最初の関門である。
  • Applied Materials MAX OLED — 段階： 顧客ラインへの導入過程。 フォトリソグラフィで画素を形成するマスクレス基盤で、Visionox V5 の蒸着に AKT の縦型装置が入った[18]。FLiPP が MAX OLED 基盤ではないかとの観測に対し、LG Display の調達が YAS に寄ったことは「自社方式」寄りの材料と報じられた[19]付随資料 — マスクレスの標準争いは、装置の売り先争いと一体である。
  • 印刷 RGB（IJP OLED）— 段階： G8.6 で世界初の量産ライン立上げ中。 JOLED が量産化に失敗した方式[15]を、CSOT が t8（295億元、月産22,500枚）で再挑戦する[16]。印刷は材料利用効率が高く、TCL は従来比 約20%のコスト低減を主張する（会社説明、報道経由）[16]付随資料。量産は2027年Q4計画で、歩留まりの実績が出るまでは「計画」として扱う。Kateeva の YIELDjet は RGB 印刷ではなく TFE 印刷で量産実績を持ち[39]、両者は分けて理解する必要がある。
  • QD-OLED vs WOLED vs RGB — 段階： いずれも量産（TV／IT で棲み分け）。 TV は WOLED（LG Display）と QD-OLED（Samsung Display）の2方式が既存 G8.5 ラインで競い、新規投資は止まっている。IT・モバイルは RGB 並置（蒸着）が標準で、タンデム化が進む。方式の優劣よりも「どの方式のラインが既に減価償却を終えたか」が装置需要を決める — 新規装置需要が出るのは RGB-IT（G8.6）とマスクレス転用の局面だけである。
  • OLEDoS の RGB 直接パターニング — 段階： 実証。 eMagin の dPd は色フィルタなしの RGB 直接形成で高輝度化する技術で、Samsung Display が買収で確保した[31]。Canon Tokki の12インチ RGB OLEDoS 蒸着はデモ段階（アライメント ±1μm の実演に対し、量産には0.1μm級が必要との報道）[38]。量産装置の標準が固まる前の工程であり、Sunic の先行（累計10台超の納入[38]）がどこまで守れるかが論点である。
  • MicroLED — 段階： 研究〜試作（本稿では監視項目）。 DSCC の装置支出には MicroLED（ガラス基板分のみ）が含まれるが構成比は小さく[3]、量産装置の市場としては未成立。OLED 装置の代替ではなく、長期の置換リスクとしてのみ扱う。

9. 政策・規制

段階を分けて記す（要望／計画・選定／実施済み）。

  • 中国（実施済み、案件単位）： 地方政府の共同出資モデル。 ファブ運営会社への地方政府の過半出資が常態化している。歴史的事例では、BOE 重慶 G6 OLED（総投資465億元）で重慶市側が25億ドル規模を負担し、BOE の持分は38.46%だった[23]。合肥市は BOE の G6 LCD（総投資175億元）で最大90億元の裏付けと85億元の融資組成を行ったとされる[23]付随資料（二次資料経由）。直近でも合肥市政府系ファンドが Visionox への出資を4.12億ドル積み増して持分31.9%とした[17] — 装置発注の持続性は、パネルメーカーの業績ではなく地方財政の意思に連動する。これは政策支援であると同時に、過剰能力の構造的原因である。
  • 韓国（実施済み）： 国家戦略技術としての税制優遇。 ディスプレイは国家戦略技術に指定され、事業化設備投資に基本15%＋3年平均超過分への追加10%の投資税額控除、R&D 費用は最大40%の控除が適用される（制度の現行内容）[22]。
  • 韓国（選定済み）： 国家成長ファンド。 LG Display は国家成長ファンドの「OLED 技術リーダーシップ」案件に選定され、ファンドからの1.5兆ウォンと自己資金を合わせた3兆ウォンを次世代 OLED（タンデム、LTPO 等）の設備・基盤に投じる[21]（2026年7–8月公表）。
  • 韓国（計画段階）： 先端ディスプレイ国家研究プラットフォーム。 産業通商資源部の事業（総額3,688.7億ウォン、うち国費2,789億ウォン、2027–2033年）が2026年11月5日に予備妥当性調査を通過した[22]付随資料。牙山に研究拠点を置き、試作検証期間の短縮（6カ月 → 1カ月）を狙う。予算成立前の計画段階として扱う。
  • 韓国（要望段階、未実施）： Samsung Display は税額控除の繰越期間の10年 → 20年延長とサンセット条項の撤廃を、LG Display は税額控除の現金還付（直接還付）制度の導入を、それぞれ2026年10月の政策討論会で要望した[22]。いずれも業界要望であり、法制化されていない。
  • 日本： ディスプレイ装置に特化した現行の支援制度は本稿の確認範囲では未取得。歴史的には INCJ が JOLED に累計約1,390億円を投融資し、破綻で最大の損失を被った[15] — 日本の政策関与は「支援の失敗例」として残り、現在の装置メーカー（Canon／Nikon／Ulvac 等）は補助金ではなく工程寡占で競争している。
  • 輸出管理： FPD 装置そのものの対中輸出規制の新措置は本稿の確認範囲では未取得（半導体装置の規制は No. 14 の範囲）。中古ラインの中国への移設（JOLED 装置の事例[15]）は、規制次第で将来の論点になりうる。

10. 見通しとシナリオ

数量面の独自予測モデルは構築しない（工程別の公式市場規模が未取得のため）。機関予測の最新ヴィンテージ[2]を軸に、案件の成否で分岐するシナリオとして整理する。

シナリオ 内容 含意
基準（機関予測に整合、独自仮定） 装置支出は2026年108億ドル[2]のピークの後、2027年に55億ドル（−49%）へ落ちる。B16 Phase 2 と V5／t8 の立上げが2027年の下支えになるが、B16 級の新規大型案件は出ない。IT OLED のパネル需要（ノートPC +50%／2026年[2]付随資料）は伸び続け、2028年以降に MacBook Air の OLED 化を巡る第2波の投資判断が来る 装置メーカーは2027年に「受注の谷」を迎える。2026年の受注残の検収管理と、サービス・改造比率の引上げが各社の収益を決める。Sunic 型の専業は振幅が最大、Canon 型の複合 BU は最も安定
強気 B16 の歩留まりが早期に安定し、BOE が Phase 2 を前倒し。Visionox V5 の ViP 歩留まりが IT サイズで実証され、Tianma／CSOT がマスクレス投資に追随。LG Display が FLiPP 投資を2027年に決定し、YAS／Sunic に大型発注が出る。OLEDoS の量産投資（Samsung Display の RGB 蒸着等[38]）も立ち上がる 2027年の落ち込みが浅くなり、マスクレス関連（露光・蒸着・検査）の装置需要が新しい柱になる。蒸着の供給者競争は価格ではなく「マスクレス対応力」で決まる局面へ
弱気（反証側） スマートフォン OLED の減少（2026年 −7%[42]）が IT の伸びを相殺し、パネル価格下落（モニタ用は2027年に約300ドルへ[33]）がパネルメーカーの投資余力を削る。中国の地方財政の制約で V5／t8 の後続フェーズが遅れ、検収遅延が装置メーカーの CF を圧迫する。B16 の歩留まり問題が蒸着装置の評価問題に発展する JOLED 型の「技術は正しいが事業が持たない」事例が再び出る。装置メーカーの与信管理（前受金比率、地方政府保証の有無）が株価の差になる

11. カタリストとリスク

カタリスト（時期が読めるもの）： - BOE B16： Phase 2 の蒸着源入札の結果（2026年11月の入札[11]付随資料）と、Phase 2 装置の検収・売上計上の時期。歩留まり関連の開示。 - TCL CSOT t8： 2027年Q4の量産開始計画[16]に向けた装置搬入の進捗と、印刷方式の歩留まりに関する最初の発信。 - Visionox V5： 2027年目標の Phase 1 量産[18]と、ViP の IT サイズ歩留まりの公表値。 - LG Display： FLiPP 投資の決定（2027年上期が一つの目安と報道[19]付随資料）と、YAS 初号機の正式発注。 - Samsung Display： A6 の Apple 向け量産の安定化と、次期ライン（A7）投資の正式表明の有無。RGB OLEDoS 蒸着装置の発注（Q4 との報道[38]）。 - Counterpoint/DSCC の四半期レポート： 2027年予測（55億ドル[2]）の改訂方向が、装置各社の受注ガイダンスに先行する。

リスク： - 2027年の需要の崖。 最新ヴィンテージでも −49%[2]とされ、2026年のピークに合わせて能力を増やした供給者（Sunic の平沢工場[12]付随資料）ほど固定費負担が重くなる。 - 検収・回収リスク。 装置の売上はパネルメーカーの検収で立つ。中国案件ではファブ運営会社の地方政府出資比率が高く[23]、回収は地方財政に連動する。Sunic の2026年上期の赤字転落[12]は検収タイミングの振れの実例である。 - 技術置換リスク。 マスクレス（ViP／FLiPP／MAX）が IT サイズで実証されれば、FMM 前提の蒸着装置の価値と FMM 供給網が同時に再評価される。逆に歩留まりが立たなければ、投資したパネルメーカー（Visionox、LG Display）の財務が傷む。 - 単一顧客・単一案件リスク。 蒸着は1ラインで数千億ウォン級の受注が立つ[11]ため、1案件の遅延・喪失がそのまま業績の欠落になる。 - 価格競争の常態化。 Sunic の約半値[11]が「新基準」になれば、Tokki の価格体系と Canon Industrial BU の利益率に下押し圧力がかかる。

反証条件（thesis が崩れるサイン）： 1. Counterpoint/DSCC の次回ヴィンテージで2027年の装置支出予測が70億ドル超へ上方修正される（＝大型案件の第2波が実在する）。 2. B16 の歩留まり問題が蒸着工程起因と特定され、Sunic の追加受注が止まる（＝「半値でも認定は維持される」という前提の崩壊）。 3. LG Display が FLiPP を断念し、通常の G8.6 新ライン投資に転換する（＝マスクレス転用戦略の否定）。 4. Apple の MacBook Air OLED 化が延期・中止され、IT OLED の第2波の根拠が消える。 5. 中国の地方政府出資案件で装置代金の支払遅延が表面化する。
